# 照片和视频下载

记录详情中的每张照片（包括封面）、照片放大窗口、视频播放器下方都有单文件下载按钮和大小。时光相册点击进入记录详情后使用相同入口。示例插画不提供下载按钮。

已登录家庭成员可以下载本家庭的有效文件，不要求管理员或上传者身份。后端每次从会话重新加载用户、家庭成员关系和注销状态，再校验文件、记录的家庭范围与删除状态，以及孩子档案是否有效。访客分享令牌不能访问该接口；回收站或归档内容须先恢复。

## 接口与传输

- `GET /api/growth/media/{id}/download`：返回附件，文件名为 `拾光-记录日期-文件编号.jpg/png/mp4`，使用 UTF-8 文件名编码。
- 同路径 `HEAD`：校验权限及存储对象是否存在，返回文件信息，不读取文件内容。前端用其展示登录失效、文件不可用等提示。
- 预览和下载共用 `GrowthMedia.write` 中的权限查询及流式读取。MinIO 通过 `GrowthObjectStorage` 读取，服务器使用 64 KiB 缓冲，不将整段视频读入内存。
- 沿用单段 Range 处理：有效范围返回 206，无效范围返回 416；多范围或带 If-Range 的请求退回完整实体。HEAD 返回完整文件信息。
- 实际下载交给浏览器，不使用前端 Blob 缓存大文件。页面的“已发起下载”仅表示已交给浏览器，不表示传输已完成。HEAD 与 GET 之间如果权限或文件状态改变，GET 会重新校验并拒绝；传输过程中断由浏览器显示下载结果。
- 下载内容是当前存储对象。照片上传时已重编码、移除 EXIF；视频未转码。当前不保留上传原始名称，生成名称适用于历史文件，无需数据库迁移。
