# 拾光 · 儿童成长记录网站（MySQL + MinIO）

## 本次范围

依据《儿童成长记录网站_需求补全方案》，保留你确认的「奶油白、鼠尾草绿、家庭相册感」。在首版本地存储基础上，按后续要求切换为 MySQL 业务数据库与 MinIO 照片 / 视频存储。

所给材料是补全方案，未提供原始 SRS / SDD / DD。本版本落实本地使用流程，未声称完成三期生产建设。

## 启动与访问

在 IDEA 中重新加载 Maven，使用 Java 17 或更高版本运行 `org.example.springaidemo.SpringaiDemoApplication`。默认启用 `mysql` profile。工作目录固定为项目根目录，以便兼容读取旧本地媒体。

- 网站首页：`http://127.0.0.1:8080/`
- 原有 AI 调试台：`http://127.0.0.1:8080/ai-chat.html`
- 分享页面：`/share.html?token=随机令牌`
- 默认服务地址：`127.0.0.1:8080`，只在本机可访问。

没有 Node.js 工程，不需要 npm 安装或前端打包。JDBC、MySQL 驱动、MinIO SDK、BCrypt 依赖已加入 Maven，H2 运行依赖已移除。家庭业务不调用 AI，也不需要模型密钥。

### 两种开始方式

**体验示例空间**：每次点击会在后端新建独立演示家庭，包含虚构的「小禾」、7 条日记/里程碑和 6 次测量。插画是项目内 SVG，不是儿童照片，不计入上传照片数量或空间用量。示例内容可操作并保存，但示例账号没有可登录的手机号密码；退出、服务重启或会话到期后，无法再次登录该示例。演示数据会保留在 MySQL 中，当前没有自动过期清理。

**创建自己的家庭**：注册手机号、密码、昵称，并填写 QQ 邮箱和邮件收到的六位验证码；邀请码留空则创建空家庭，再添加孩子档案。输入邀请码则加入现有家庭。手机号仅作账号格式标识，未验证手机号所有权；QQ 邮箱须通过验证码验证。密码最少 8 个字符，最多 60 个字符，并限制 BCrypt 输入最多 72 UTF-8 字节。旧用户可在个人资料绑定邮箱，原登录不受影响。[邮箱验证与待办提醒说明](QQ邮箱验证码与待办提醒.md) 包含本次必须执行的升级脚本及 Nacos 配置。

### 使用 MySQL（8.0 / 8.4）

`growth/schema.sql` 是 H2 脚本。MySQL 的 `CREATE INDEX` 没有 `IF NOT EXISTS` 选项，所以在 MySQL 客户端执行它会出现 1064。只去掉这几个单词仍会留下重复执行报错和列内 `REFERENCES` 被忽略的问题。

1. 在 SQL 客户端选中专门用于本项目的数据库，以 UTF-8、遇错停止的方式执行整个 `src/main/resources/growth/schema-mysql.sql`。客户端需要识别 `DELIMITER`，不能只选中过程体中的某一条语句执行。
2. 脚本适用于空库，或原 H2 脚本已在 MySQL 创建了部分项目表的情况。它补建剩余表，通过 `information_schema` 检查和补齐索引/表级外键，不删除已有表或数据。已存在同名索引但定义不同会报错停止；孤儿数据导致外键无法建立时也会停止，不会关闭外键检查或自动删除数据。
3. 账号需要表结构修改权限和创建/执行/清理辅助存储过程的权限。脚本内的两个 `growth_ensure_*_20260928` 过程专用于本次补齐，结束后删除。不要并发执行该脚本。DDL 会隐式提交，某一步失败不等于前面的步骤已回滚，确认报错原因后可重跑。
4. 默认启用 `mysql`，如 IDEA 启动配置覆盖了 Active profiles，请包含 `mysql`，或配置环境变量 `SPRING_PROFILES_ACTIVE=mysql`。
5. `application-mysql.yml` 已保留你填写的 `growth` 数据库名及截图中的服务连接信息，无需再填写原来的 `growth.mysql.database` 空项（已移除）。若另一个环境需要覆盖连接信息，仍支持以下可选变量：

```text
GROWTH_MYSQL_URL=jdbc:mysql://127.0.0.1:3306/你的数据库名?useUnicode=true&characterEncoding=UTF-8&connectionTimeZone=Asia/Shanghai
GROWTH_MYSQL_USERNAME=你的数据库账号
GROWTH_MYSQL_PASSWORD=你的数据库密码
```

SQL 自动初始化已关闭，含客户端分隔符和辅助过程的 MySQL 脚本只由你手动执行。应用不再默认使用或回退到 H2；已完成 MySQL 建表时，此次 MinIO 接入无需新建字段。

同一配置文件包含 Redis 连接信息（`spring.data.redis`）和已接入业务的 MinIO 配置（`app.minio`）。Redis 暂未接入会话。MinIO API 使用 9000 端口，9001 仅为控制台；bucket 为 `shiguang-media`，首次上传自动创建私有桶，不设置公开下载策略。账号需拥有桶存在检查、建桶、上传、读取和删除对象权限；预建桶时可关闭 `auto-create-bucket`。

可用 `GROWTH_MINIO_ENDPOINT`、`GROWTH_MINIO_ACCESS_KEY`、`GROWTH_MINIO_SECRET_KEY`、`GROWTH_MINIO_BUCKET` 覆盖对应配置。对象路径为 `families/家庭ID/UUID.扩展名`，数据库 `oss_key` 保存 `minio/bucket/对象路径`，更换默认 bucket 后仍能按旧 bucket 定位对象（服务端地址及账号仍需可访问旧桶）。浏览器不获取 MinIO 凭证或直接访问对象，不需要对 bucket 开放 CORS。

这份脚本不会搬迁 H2 中已有的账号和记录，也不会改造其他业务系统的同名表、修复旧表任意字段差异或更改旧表字符集。新表使用 InnoDB / utf8mb4。切换库后，本地图片目录保持原位置，但新库不会自动取得旧库的媒体元数据。

此 MySQL 路径只完成源码适配与阅读审查，未连接你的数据库、未执行 SQL、未编译或联调；请在选定的测试库手动验证注册、示例数据、上传、删除恢复和分享。

语法依据：[MySQL CREATE INDEX](https://dev.mysql.com/doc/refman/8.0/en/create-index.html)、[MySQL CREATE TABLE](https://dev.mysql.com/doc/refman/8.0/en/create-table.html)。

### 照片与视频规则

- 照片支持 JPEG / PNG，每张不超过 8 MiB；视频支持 MP4，每个不超过 100 MiB。
- 照片和视频可混合上传，每次最多 25 个、合计不超过 500 MiB，每条记录最多 25 个文件。Servlet 总请求上限为 501 MiB，给 multipart 表单边界预留空间；文件合计仍由业务层限制为 500 MiB。
- 服务器验证图片实际格式；视频检查 `ftyp` 品牌、容器块边界、`moov` 中的视频轨道以及非空 `mdat`。拒绝纯音频 MP4、容器不完整或简单改名伪装的文件，但不解码所有视频帧，不能据此保证每一帧都有效。
- 视频通过临时文件校验后流式上传到 MinIO，不整体加载到 Java 堆。临时文件在请求结束时删除；服务器需要临时磁盘空间，进程强杀留下的临时文件由运维清理。保留原视频内容和元数据，不执行压缩、转码、水印或 EXIF 清除。推荐 H.264 / AAC MP4；MOV、AVI、WebM 暂不支持，浏览器不支持的编码会显示播放失败提示。
- 视频只在记录详情及待上传预览中加载播放器，时间线和相册使用视频标识卡片，避免列表同时请求所有大视频。详情支持浏览器原生播放、暂停、音量、全屏及进度控制。关闭弹窗后停止播放并释放本地预览 URL。
- 上传视频期间显示上传状态，禁止重复提交或关闭上传弹窗（不能阻止手动关闭整个浏览器页面）。尚未实现上传百分比、断点续传或跨请求幂等；网络中断导致结果不明确时，先刷新确认是否已保存，再决定重试。
- 最大 2500 万像素，图片重新编码，去除原 EXIF 元数据。当前不根据 EXIF 自动旋转，手机照片可先旋转后上传。
- 记录正文与媒体为两次请求：正文先保存，上传失败会明确提示「文字已保存」，保留记录 ID，重试会编辑同一条记录。
- 照片和视频在静态资源目录之外。家庭媒体端点对每次请求校验登录、家庭归属和删除状态。
- 当前不支持单独移除某一张照片或某个视频，可将整条记录移入回收站。

### 权限与数据归属

- 家庭支持多位管理员。管理员可在「家庭成员」中授予或取消其他成员的管理员权限；普通成员可查看全家孩子、上传、评论，只可编辑/删除/分享自己发布的记录。创建者不可被移出或取消管理员权限，也不能操作自己的角色。
- 管理员可编辑/删除/分享家庭内全部记录，并管理孩子、成员、回收站、空间、导出和日志。
- 成长测量及接种记录：保留家庭成员原有的查看、新增权限；编辑和删除仅限家庭管理员，后台同时校验记录及目标孩子的家庭归属。修改测量日期或孩子时重新计算月龄，并保留原始录入人；实际修改者记录在操作日志中。
- 测量和接种数据删除前显示确认提示，确认后直接删除，不进入成长日记的回收站。保存或删除后重新加载快照，更新测量列表、曲线、最新数值、接种列表及后续导出数据。
- 当前支持角色变更和移出其他管理员；不提供创建者转让、多家庭切换、孩子级授权，家庭至少保留一位管理员。
- 每次业务请求从会话中的用户 ID 查询当前家庭关系；前端不能指定可信的 familyId、userId，仅管理员专用角色接口接受目标角色，并校验当前家庭、操作者和受保护成员。重要写入在取得家庭锁后重新核对当前成员身份和角色，拒绝等待过程中已被降权或移出的请求。
- 资源查询使用参数化 SQL，显式校验家庭和资源归属。成员被移除后，已有会话下次访问即失效。已发布内容保留，当前移除后同账号重新加入尚未实现。
- 密码使用 BCrypt。Cookie 设置 HttpOnly / SameSite=Strict；写接口要求同源自定义头，不开放跨域 CORS，拒绝浏览器声明的跨站写请求。
- 媒体与业务响应不缓存。前端用户文字做 HTML 转义。

### 孩子档案回收站

管理员可在「家庭成员 → 孩子的小档案」删除档案，确认后移入可恢复的档案回收站。关联日记、照片视频、测量和接种记录隐藏并保留，媒体仍计入原有空间占用；此时不会写入文件清理队列。

在「回收站 → 孩子档案回收站」恢复后，原有正常资料重新显示，之前单独删除的成长记录仍在成长记录回收站，旧分享保持撤销。隐藏期间不能通过记录修改、照片视频直链、成长数据修改、导出或 AI 接口绕过档案状态校验。无需新增数据库字段，复用 `child.is_active`。

档案回收站同时提供「彻底删除」。管理员确认不可恢复的删除范围后，事务内清理该孩子档案及全部关联记录（含记录回收站）、评论、标签关联、媒体元数据、分享、关联通知、测量、接种和 AI 请求状态，并将照片视频加入 `media_cleanup` 队列异步清理。家庭共享标签和其他孩子资料保留。后端拒绝直接永久删除活动档案、跨家庭删除或普通成员操作；与恢复共用家庭行锁。此次功能无需新增 SQL。

详细权限边界及手动验收见 [家庭权限与档案回收站说明](家庭权限与档案回收站说明.md)。

### 回收站、配额和文件一致性

默认家庭配额 **5 GiB（页面显示 5.0 GB，5368709120 字节）**，按重编码后的有效图片与原视频实际字节数合计计算。上传和恢复在事务中锁定家庭行再核算配额，避免同一家并发超额。新注册家庭和示例家庭均显式使用新配额。

已有数据库请手动执行 `src/main/resources/growth/upgrade-storage-quota-5gb.sql`，更新表默认值，并把仍为旧默认 512 MiB 的家庭扩容至 5 GiB；其他自定义配额保持不变。只修改初始化脚本不会改变已有家庭。执行后刷新页面即可看到新容量，单文件及单次上传限制保持原值。

软删除同一事务更新记录与媒体状态，并将关联分享状态设为撤销。恢复检查剩余配额，旧分享不会重新生效。

彻底删除同一事务删除记录/评论/标签关联/媒体元数据/分享，并将文件 key 放入 `media_cleanup`。后台任务启动 30 秒后运行，每轮结束 60 秒后再处理最多 100 个到期任务；文件删除成功才移除任务，MinIO 或数据库故障会保留以便重试，重复删除不存在对象视为成功。

上传先在独立事务持久化清理意图（`media_cleanup.create_time` 此时表示一小时后的可清理时间），再锁定家庭行上传对象、写媒体元数据并删除对应意图。整批业务事务回滚时，元数据全部撤销，意图仍保留并提前到可重试状态；进程强杀则等待一小时后清理。清理与上传使用同一家庭行锁，清理前重查队列和所有媒体引用，避免误删仍被引用或正在上传的对象。该机制处理本应用登记的对象，不扫描、删除桶内其他文件。

回收站不计入有效媒体配额，但文件仍占存储空间。容量统计使用 MySQL 聚合查询，另展示回收站字节数；并非整个 MinIO 桶的使用量。请保持本应用桶为私有且不启用版本保留 / 对象锁；启用版本保留时普通删除只创建删除标记，旧版本仍占用空间，本应用尚未管理历史版本。

### 限时分享

- 令牌由两段随机 UUID 组成，页面链接不含记录 ID。
- 可选 1 / 3 / 7 天，最多 1–1000 次访问。
- 每次打开分享页算一次访问；条件更新保证并发访问不能突破上限。一次访问中的多张图片不重复计数；视频不参与分享，直接请求视频编号也会被拒绝。
- 访客仅能查看对应单条文字和图片预览，不开放视频，不返回家人手机号、评论或其他家庭记录。
- 分享图片会缩小到最长边 1280 像素，并将重复水印烧录进 JPEG；访客拿不到家庭原图端点的授权。
- 到期、撤销、删除记录后，后续访问被拒绝。已经加载到访客设备上的内容无法撤回；无法阻止截图。
- 本机地址生成的链接只能本机体验。供真实家人跨设备使用需部署到可达地址，并完成 HTTPS 等上线工作。

### 导出

管理员可以按孩子导出 JSON，包含档案、有效成长记录、关联照片/视频编号、评论、标签、测量和接种记录。不包含照片或视频二进制，不含回收站数据，不提供导入恢复或全量打包。

## 与方案的实现差异

| 方案设计 | 当前选择 / 边界 |
| --- | --- |
| MyBatis + MySQL + 家庭拦截器 | JDBC + MySQL，默认启用 mysql profile；现有 SQL 显式带家庭条件，没有自动注入的 MyBatis 拦截器。新增查询必须遵循归属校验约定 |
| Redis token | 本机 HttpSession；重启后重新登录，业务数据保留 |
| OSS 直传、分片、断点续传 | 浏览器 multipart 上传至后端，再由 MinIO SDK 存储对象，不含浏览器直传/断点续传 |
| 异步操作日志 | 与业务事务同步写入，保证修改与审计一起提交；尚未接队列 |
| 定时更新 storage_used | MySQL 按 family 聚合有效媒体；单位统一为字节，页面转换显示 |
| 每年今日通知推送 | 页面按当天日期计算回忆，未做离线定时通知生成 |

## 手动验收路径

以下是建议验证项，不是已经执行的结果。本次未编译、未启动、未运行自动化测试、未做浏览器或接口实测。

1. 启动后进入首页，体验示例空间；检查桌面与手机宽度下导航、卡片、弹窗和表格。
2. 注册一个真实测试家庭，创建两个孩子，切换孩子并确认时间线/成长数据互相独立。
3. 发布带两个标签、两张图片的日记，刷新后查看详情、编辑正文、追加图片、发表评论。
4. 添加里程碑；尝试关键词、月份、类型、顺序筛选，再检查相册关联记录。
5. 添加两次同月测量和一次不同月测量，切换身高/体重/头围；检查所有测量点和下方表格。输入生日以前或未来的记录日期应被拒绝。
6. 创建邀请码，用无痕窗口注册第二位成员；成员应可查看和评论管理员记录，但不能修改/删除管理员记录，不能访问管理页面与管理接口。
7. 另建独立家庭，手动替换请求中的记录、孩子或媒体 ID，确认读取/修改均被拒绝。
8. 创建限时分享，无痕窗口打开，查看水印图；设置访问上限为 1 后再次打开应失败。撤销或删除原记录后，旧链接应失败。
9. 删除带图片的记录，核对有效配额下降；恢复后配额增加，旧分享不恢复；永久删除后确认数据库记录删除，并等待清理任务处理 MinIO 对象。
10. 验证非法文件、超限图片、超配额上传和图片上传失败的错误提示；正文已保存时再次提交不应新建重复文字记录。
11. 导出孩子 JSON，检查结构化内容和不含原图的说明；查看对应操作日志。
12. 重启应用，重新登录真实账号，确认记录、图片、成员、测量仍在。原 AI 页面和接口仍可按原流程使用。
13. 管理员编辑测量数值、日期、备注，将可选头围清空；检查月龄重算、曲线及最近测量同步更新。删除最新或最后一条测量，检查最新数值回退或变为空状态。
14. 编辑疫苗名称、剂次、日期、接种机构和备注；取消删除时保持原数据，确认删除后刷新仍不存在，操作日志能查到记录编号。
15. 普通成员仍可新增、查看，但 PUT / DELETE 请求应返回 403；管理员传入其他家庭的记录 ID 或目标孩子 ID 应被拒绝。编辑生日以前 / 未来日期及超范围测量值应失败，记录保持原值。

## 视频功能手动验收补充

本次仅完成代码修改与阅读审查，没有运行编译、数据库操作、接口请求或浏览器测试。已完成 MySQL 建表时无需新 SQL，沿用 `media_file.mime_type / oss_key / size_bytes` 和 `media_cleanup` 等字段。

1. 重启应用、刷新首页，新建一条仅含 MP4 的记录；确认时间线显示视频卡片，详情能播放、暂停、拖动进度，刷新后仍可播放。
2. 新建一条混合照片和视频的记录；检查照片展示、视频播放器、卡片数量和家庭容量合计。给已有照片记录追加视频，确认原照片仍在。
3. 验证大于 8 MiB 的图片、大于 100 MiB 的视频、文件总量超过 500 MiB、超过 25 个文件、单记录累计超过 25 个文件、空间超额时均有明确错误。
4. 把文本/图片改名为 .mp4、上传仅音频 MP4 或不完整文件，应被拒绝；同批上传失败时，媒体元数据回滚，已上传对象由队列异步清理，已保存正文保留。
5. 删除带视频记录，确认播放接口被拒绝；恢复后能播放且重新占用配额；永久删除后等待清理任务移除 MP4 文件。
6. 用另一家庭或未登录窗口直接请求视频地址，应被拒绝；同家庭成员可以播放。
7. 分享混合记录时，访客只得到文字和图片水印预览，并看到视频不包含在分享中的说明；将分享图片 URL 中 ID 替换为视频 ID 也应被拒绝。
8. 关闭正在播放的详情弹窗，确认声音停止；选择新文件、关闭待上传预览后不应继续播放。

媒体接口先校验家庭权限，再返回 200 全文或 206 单范围；非法 / 越界范围返回 416，HEAD 无正文，多范围与带 If-Range 的请求回退到 200。通过 MinIO SDK 的 `offset/length` 仅读取需要的字节，输出使用固定大小缓冲区。参考 [MinIO Java SDK 8.6.0 getObject 示例](https://github.com/minio/minio-java/blob/8.6.0/api/src/main/java/io/minio/MinioClient.java)。实际 Range 返回与播放器兼容性仍待手动验证。
